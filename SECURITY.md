# Security

Supported version: 0.1.x. Please use GitHub's private vulnerability reporting at https://github.com/KanadeK/csv-relation-check/security/advisories/new when available. If it is unavailable, open an issue asking for a private contact without including vulnerability details, secrets or sample customer data.

The tool runs locally with your user permissions. Reports can contain metadata supplied by you; review reports before sharing them. It performs no network requests and does not execute input as code. Resource limits are operational guards, not a hostile-process sandbox. See README limitations for the precise validation boundary.
